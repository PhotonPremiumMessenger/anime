# ⛩ Nihongo — учи японский через аниме

Фронтенд платформы **Nihongo**: разбор фраз, пасхалок и культурных отсылок из аниме для русскоязычных анимешников.

Сайт написан на чистом HTML, CSS и JavaScript — без React, Vue и сборщиков. Каждый файл можно открыть и прочитать: код с комментариями на русском.

---

## 🚀 Быстрый старт

1. Скачай папку проекта.
2. Открой файл **`index.html`** в браузере (двойной клик).

Всё. Это статический сайт, сервер для него не нужен.

### Вариант с локальным сервером

Если браузер ругается на запросы к API или хочется проверить всё «как на хостинге»:

```bash
# из папки проекта
python -m http.server 8000
# затем открой http://localhost:8000
```

Или через Node.js:

```bash
npx serve .
```

## ⚠️ Важно про API

Фронтенд обращается к уже существующему бэкенду:

```
http://194.55.236.245:8080
```

Адрес задаётся в одном месте — константа `API_URL` в `js/api.js`.

Что нужно, чтобы всё работало:

1. **На сервере должен быть разрешён CORS** для домена, на котором открыт сайт.
   Без этого браузер заблокирует запросы (`fetch` вернёт ошибку соединения).
2. **Не открывай сайт по `https://`**, если API остаётся на `http://`.
   Браузер заблокирует такие запросы как mixed content. Для локальной разработки
   используй `file://` или `http://localhost`.
3. Бэкенд не входит в этот репозиторий и здесь **не изменяется** — только фронтенд.

### Как посмотреть профиль без работающего бэкенда

Профиль защищён токеном, поэтому без сервера откроется страница регистрации.
Чтобы просто посмотреть вёрстку, открой консоль браузера (F12) и выполни:

```js
localStorage.setItem('token', 'demo');
localStorage.setItem('username', 'Senpai');
localStorage.setItem('joinedAt', new Date().toISOString());
location.href = 'profile.html';
```

Потом токен можно убрать командой `localStorage.removeItem('token')`.

Если названия полей на бэкенде отличаются (`username` / `nickname`, `newEmail` / `email`),
достаточно поправить тело запроса в `js/api.js` — все остальные файлы трогать не нужно.
Сейчас в запросах регистрации и входа отправляются оба варианта имени, чтобы
подойти под любую схему.

## 📄 Страницы

### `index.html` — Главная

- Hero-блок с заголовком и кнопками «Начать бесплатно» / «Узнать больше».
- Карточка с примером разбора фразы.
- Четыре карточки «Что внутри».
- Блок **«В разработке»** с процентом готовности и таймером до релиза.
- Подвал с соцсетями и копирайтом.
- Шапка с лого, навигацией и кнопкой **«Дизайн»**.

### `register.html` — Регистрация и вход

- Две формы на одной странице, переключение через `showLogin()` / `showRegister()`.
- Регистрация: ник, почта, пароль и чекбокс согласия. Под паролем — индикатор сложности.
- Вход: ник и пароль, запоминание сессии.
- «Забыли пароль?» раскрывает блок сброса.
- Модальное окно подтверждения почты: код из 10 символов (буквы автоматически
  становятся заглавными), кнопка «Отправить код» превращается в «Проверить код»,
  ссылка повторной отправки с 60-секундной паузой.
- Toast-уведомления четырёх типов: успех, ошибка, предупреждение, информация.

**Порядок регистрации:**

```
форма → «Отправить код» (/send-code) → ввод кода → «Проверить код» (/verify-code)
      → создание аккаунта (/register) → вход (/login) → profile.html
```

### `profile.html` — Профиль

- Если в `localStorage` нет токена — редирект на `register.html`.
- Слева: круглый аватар 180×180 с оранжевой обводкой и свечением, ник, уровень,
  XP-бар, кнопка «Изменить аватар».
- Справа: статистика (3 карточки), достижения (6 иконок, открыта одна),
  лента активности, друзья, кнопки «Настройки» и «Выйти».
- Модалка выбора аватара — сетка 4×2, «Загрузить свою» пока заглушка.
- Модалка подтверждения выхода.

### `about.html` — О проекте

Hero, 4 карточки «Что такое Nihongo», 3 блока «Почему мы» (сдвиг вправо при наведении),
3 шага «Как это работает», FAQ-аккордеон из 6 вопросов и финальный CTA.

### `settings.html` — Настройки

Шесть разделов в левом меню:

| Раздел | Что внутри |
| --- | --- |
| **Аккаунт** | Смена пароля, почты и ника (раз в 30 дней), Discord, Telegram, 2FA, выгрузка данных, удаление |
| **Звук** | Общая громкость, музыка, звуки кнопок, уведомлений и перевода |
| **Интерфейс** | Язык, тема, фон, курсор, размер шрифта, анимации, компактный режим |
| **Уведомления** | Уроки, аниме, друзья, достижения, дейли-напоминание, email-рассылка |
| **Лаунчер** | Публичный профиль, прокси, DNS (лаунчер ещё в разработке) |
| **Фишки** | Стиль перевода, транскрипция, пасхалки, уровень сакуры, стиль аватара |

Работают по-настоящему: смена пароля, смена ника и смена почты с подтверждением кодом.
Остальные настройки сохраняются в `localStorage` и показывают toast
**«Сохранено (заглушка)»**. Часть из них сразу меняет внешний вид сайта:
тема, фон, размер шрифта, анимации, компактный режим, форма аватара и сакура.

## 🔌 API

Все запросы собраны в `js/api.js` и возвращают `{ ok, data }`.

| Функция | Метод и путь | Назначение |
| --- | --- | --- |
| `apiSendCode(email)` | `POST /send-code` | Отправить код на почту |
| `apiVerifyCode(email, code)` | `POST /verify-code` | Проверить код |
| `apiRegister(nick, email, pass)` | `POST /register` | Создать аккаунт |
| `apiLogin(nick, pass)` | `POST /login` | Войти, получить JWT |
| `apiResetPassword(email)` | `POST /reset-password` | Сброс пароля |
| `apiChangePassword(old, new)` | `POST /change-password` | Смена пароля |
| `apiChangeNickname(nick)` | `POST /change-nickname` | Смена ника |
| `apiChangeEmailRequest(email)` | `POST /change-email-request` | Код на новую почту |
| `apiChangeEmailConfirm(email, code)` | `POST /change-email-confirm` | Подтвердить новую почту |

Защищённые запросы отправляют заголовок `Authorization: Bearer <token>`.

**Выход** выполняется только на клиенте: `logout()` очищает `localStorage`
и ведёт на главную.

## 💾 Что хранится в localStorage

| Ключ | Значение |
| --- | --- |
| `token` | JWT после входа |
| `username` | Ник игрока |
| `avatar` | Путь к выбранному аватару |
| `joinedAt` | Дата первого входа (для профиля) |
| `releaseDate` | Дата релиза для таймера (не сбрасывается при перезагрузке) |
| `theme` | Тема: `default` или `sakura` |
| `sakuraOn` | Включены ли лепестки |
| `settings` | JSON со всеми настройками |
| `pendingEmail` | Почта, ожидающая подтверждения кодом |
| `nickChangedAt` | Когда менялся ник (ограничение 30 дней) |

## 🎨 Дизайн

Тёмное «стекло» с оранжевым акцентом. Всё построено на CSS-переменных
в начале `css/style.css`:

```css
--bg-dark:    #0a0a10;   /* глубокий фон */
--accent:     #FFB347;   /* оранжевый акцент */
--accent-dark:#B7410E;   /* тёмно-оранжевый */
--text-main:  #FFFFFF;
--text-gray:  #B8B8B8;
--text-dim:   #6A6A6A;
--border:     rgba(255, 255, 255, 0.08);
--transition: 0.25s cubic-bezier(0.4, 0, 0.2, 1);
```

- **Шрифты:** Russo One (заголовки) и Noto Sans JP (текст) из Google Fonts.
- **Компоненты:** кнопки (primary, outline, ghost, large, small, icon), карточки,
  табы, чипы, поиск, формы, модалки, toast.
- **Шапка:** sticky, 64 px, `backdrop-filter: blur(18px)`.
- **Темы:** «Стандарт» и «Сакура» — переключаются в панели «Дизайн» и в настройках.
- **Сакура:** лепестки падают сверху, количество зависит от «уровня сакуры».
- **Скроллбар:** кастомный, оранжевый.
- **Адаптивность:** пока не делалась — только ПК-версия, как и планировалось.

### Перевод по выделению

Выдели текст на любой странице — над ним появится попап с переводом.
Русский переводится на японский, японский — на русский. Используется
`translate.googleapis.com`, а при недоступности — резервный `mymemory.translated.net`.
