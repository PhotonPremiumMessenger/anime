# ⛩ AniLingo — учи японский через аниме

**Фронтенд — чистый HTML, CSS и JavaScript на GitHub Pages. Бэкенд — Node.js + Express + SQLite в папке `server/`.**

Платформа AniLingo: разборы фраз, пасхалок и культурных отсылок из аниме
для русскоязычных анимешников. Без React, Vue и сборщиков: сайт — набор
страниц, данные приходят с собственного API.

Сайт умеет работать в двух режимах:

| Режим | Когда включается | Где живут данные |
| --- | --- | --- |
| **Сервер** | `GET /api/health` ответил | SQLite на сервере, синхронизация между устройствами |
| **Демо** | сервер не ответил | localStorage браузера, как раньше |

Режим выбирается сам при загрузке страницы — переключателей нет.
Подробности: [`server/README.md`](server/README.md).

## 🚀 Как открыть

### Локально

Скачай папку проекта и открой **`index.html`** в браузере (двойной клик). Всё.

Если браузер ограничивает `file://` — запусти локальный сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000
```

### На GitHub Pages

1. Залей ветку в репозиторий (или влей PR).
2. Открой **Settings → Pages**.
3. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**.
4. Сохрани — через минуту сайт будет на `https://<username>.github.io/<repo>/`.

Ссылки в проекте относительные, поэтому сайт работает и в подпапке, и локально.

**Для GitHub Pages бэкенд не обязателен.** Без сервера сайт открывается в
демо-режиме и хранит всё в браузере. Свой API поднимается из папки `server/`
и включает синхронизацию между устройствами. Сторонние сервисы: Google Fonts,
Google Translate (перевод выделенного текста) и Google как SMTP для писем
с кодами подтверждения.

## 🔄 Что на сервере, а что в браузере

| Данные | Где живут | Почему |
| --- | --- | --- |
| Аккаунт: ник, почта, хеш пароля | сервер, `users` | вход с любого устройства |
| Настройки интерфейса и контента: тема, шрифт, компакт, анимации, перевод, транскрипция, сакура, аватар | сервер, `user_settings`, ключ `settings` | должны переезжать между устройствами |
| Цвет сайта: свой цвет, палитра, радуга | сервер, `user_settings`, ключи `appearance.*` | выбрал на телефоне — видно на компьютере |
| Профиль: аватар, XP, уровень, оформление профиля | сервер, `user_profile` + `user_settings` | прогресс не теряется при смене браузера |
| Прогресс уроков, достижения, серия дней, ошибки, флешкарты, магазин, избранное, цели, экзамены | сервер, `user_settings`, ключи `data.*` | главное, зачем нужен аккаунт |
| Фон сайта, загруженный пользователем | браузер | картинка на несколько мегабайт |
| Плейлист и свои музыкальные файлы | браузер | то же, плюс авторские права |
| Состояние интерфейса: свёрнутые блоки, режим фокуса, помодоро | браузер | это про конкретное устройство |
| Флаги «показано приветствие», тур, согласие на cookies | браузер | состояние устройства, а не аккаунта |

Правило простое: **в localStorage лежит кэш, а не источник правды.**
При загрузке страницы данные приходят с сервера и кладутся в кэш,
чтобы интерфейс отрисовался без ожидания сети. При изменении значение
пишется в кэш сразу, а через 600 мс уходит на сервер одним запросом.

У каждой настройки на сервере есть отметка времени (`updated_at` в
`user_settings`). Клиент помнит отметки, которые видел в прошлый раз,
поэтому телефон и компьютер не затирают прогресс друг друга: если
ключ менялся здесь — уходит здешнее значение, если на другом
устройстве — приезжает его.

При выходе данные на сервере остаются, локальный кэш аккаунта
очищается. Музыка, свой фон и флаги устройства остаются на месте —
это не данные аккаунта.

## 👤 Аккаунты и сессия

На сервере пароль хранится только как bcrypt-хеш, сессия — JWT на 30 дней.

В браузере остаётся кэш, чтобы шапка и профиль рисовались мгновенно:

Все ключи ниже, кроме перечисленных в таблице выше как «браузер»,
имеют копию на сервере: при входе данные приезжают, при изменении
уходят через `PUT /api/user/settings`.

| Ключ localStorage | Что хранит |
| --- | --- |
| `nihongo_users` | Кэш текущего пользователя `{ id, username, email, avatar, xp }` |
| `nihongo_current_user` | Ник текущего пользователя (сессия) |
| `nihongo_token` | JWT с сервера (или псевдо-токен в демо-режиме) |
| `settings` | Кэш настроек, полученных с сервера |
| `nihongo_progress` | Прогресс: уроки и выученные слова |
| `nihongo_achievements` | Открытые достижения (id из списка 100) |
| `nihongo_flags` | Одноразовые отметки для достижений |
| `nihongo_streak` | Серия дней: `{ count, best, last }` |
| `nihongo_visits` | Даты заходов (две недели) |
| `nihongo_counters` | Счётчики действий для достижений |
| `nihongo_daily` | Ежедневные задания на сегодня |
| `nihongo_weekly` | Челлендж недели |
| `nihongo_quiz` | Викторина дня |
| `nihongo_speed` | Рекорд теста на скорость |
| `nihongo_shop` | Купленные и надетые предметы магазина |
| `nihongo_guest_xp` | Опыт гостя (без аккаунта) |
| `nihongo_grammar_read` | Изученные правила грамматики |
| `nihongo_lesson_steps` | Прогресс по шагам внутри урока |
| `nihongo_tests` | Лучшие результаты тестов |
| `nihongo_easter` | Найденные пасхалки |
| `nihongo_anime_shared` | Тайтлы, фразой которых уже поделились |
| `nihongo_friends` | Друзья по нику: статус заявки и дата добавления |
| `nihongo_activity` | История активности (до 120 событий) |
| `nihongo_custom` | Оформление профиля: градиент, акцент, эффект ника |
| `nihongo_jlpt` | Выбранный уровень японского (N5 / N4 / N3) |
| `nihongo_xp_days` | Опыт по дням для графика за 14 дней |
| `nihongo_srs` | Флешкарты: коробка, срок возврата и счётчики слова |
| `nihongo_exam` | Попытки пробного JLPT и лучший результат |
| `nihongo_listening` | Статистика аудирования |
| `nihongo_notifications` | Центр уведомлений (до 40 событий) |
| `nihongo_notify_level` | Последний уровень, о котором уже сообщили |
| `nihongo_weak` | Ошибки для разбора: тема, вопрос и верный ответ |
| `nihongo_goals` | Цели на день и неделю |
| `nihongo_favorites` | Избранное: тайтлы, правила и слова |
| `nihongo_autotheme` | Включена ли тема по времени суток |
| `nihongo_match` | Рекорд в «Кандзи-парах» |
| `nihongo_best_streak` | Лучшая серия дней за всё время |

**Регистрация:** ник (3–20 символов), почта, пароль (8+). Проверяется, что ник и
почта не заняты. После создания аккаунта вход выполняется автоматически.

**Вход:** ник (или почта) и пароль. При успехе сохраняются токен и ник, дальше — редирект на `profile.html`.

**Выход:** очищаются данные аккаунта (`settings`, `data.*`, `appearance.*`)
и сессия (`nihongo_current_user`, `nihongo_token`), редирект на `index.html`.
На сервере всё остаётся; музыка, свой фон и флаги устройства не удаляются.

**Защищённые страницы:** `profile.html`, `settings.html`, `lesson.html`.
Без токена — редирект на `register.html`; после входа пользователь возвращается
на ту страницу, с которой его выкинуло.

### Про код подтверждения

Код из 10 символов генерирует сервер и отправляет письмом (nodemailer,
`EMAIL_USER` и `EMAIL_PASS` в `.env`). Он действует 10 минут, привязан к
почте и после 5 неверных попыток сгорает. Не больше 6 писем в час на адрес.

Пока почта не настроена, сервер работает в демо-режиме: письмо не уходит,
а код возвращается в ответе и показывается на экране — как раньше.

> Пароли хранятся только как bcrypt-хеш — и на сервере, и в локальном
> демо-режиме. Открытым текстом пароля нет нигде.
> Для настоящего аккаунта используйте отдельный пароль, а не тот, что от почты.

## 📚 Уроки

Пять уроков в `js/lessons-data.js` (массив `nihongo_lessons`):

| № | Урок | Уровень | Время |
| --- | --- | --- | --- |

В каждом уроке: 10 слов с романдзи и переводом, блок грамматики, 4 примера

- `lessons.html` — каталог: поиск, фильтр по уровню, прогресс-бар на каждой карточке.

рядом с каждым словом и примером. Если японского голоса в системе нет, браузер

**Проверка теста:** верные ответы подсвечиваются зелёным, ошибочные — красным.
Кнопка «Завершить урок» сохраняет результат в `nihongo_progress`.

## 🎬 Видео-уроки — `video.html`

Видео **без YouTube**. Поддерживаются три источника:

1. **Локальный файл** — положи `assets/video/<id>.mp4` (например `assets/video/hiragana.mp4`),
   плеер подхватит его сам: появится настоящее видео с таймлайном.
2. **Rutube / VK** — впиши ссылку на встраивание в поле `embed` нужного урока в `js/video.js`,
   откроется iframe-плеер.
3. **Слайд-режим** — работает всегда, без файлов и интернета: 5–10 слайдов с японским текстом,
   переводом, озвучкой, таймлайном и текстом урока под плеером.

Управление: play/pause, вперёд/назад, перемотка по полосе, переключение озвучки, выбор слайда в тексте.

## 🈴 Грамматика — `grammar.html`

17 правил от N5 до N4: частицы は / が / を / に / で / も / と / の, です и ます, て-форма,
прошедшее время, вопросы, прилагательные, счётные суффиксы, から / まで, より / ほど.

У каждого правила: объяснение в 2–3 абзаца, структура, 3 примера с ромадзи и озвучкой,
подсказка и разбор частой ошибки. Кнопка «Отметить как изученное» даёт +15 XP один раз,
прогресс виден в шапке страницы. Ссылкой `grammar.html?rule=wa` можно поделиться.

## 🎌 Каталог аниме — `anime.html`

24 тайтла, у 23 есть постер. Каталог грузит облегчённые копии из
`assets/images/posters/web/<id>.webp` — 320×480, 20–40 КБ каждая, весь каталог
около 650 КБ вместо 4,7 МБ. Это свои файлы, а не ссылки на внешние CDN:
официальные японские постеры у части провайдеров в РФ не открываются,
а локальная картинка грузится при любом IP, работает офлайн и не тормозит
страницу (`loading="lazy"`, `decoding="async"`).

Если WebP не открылся, `animePosterFallback` идёт по цепочке: превью
`web/<id>.jpg` → полный оригинал `posters/<id>.jpg` → градиент с вертикальным
японским названием и большим иероглифом. Тайтлы без файла попадают в третий
шаг сразу — лишних запросов в 404 нет.



24 тайтла. У каждого: CSS-постер с кандзи, год, жанры, уровень JLPT и фраза с ромадзи
и переводом. Фильтры по жанру и уровню, поиск по названию и фразе, модалка с контекстом,
словами из фразы и озвучкой. Кнопка «Поделиться фразой» даёт +15 XP за первый шаринг тайтла.

## 🔤 Ромадзи и голос

- **Ромадзи** — латинская транскрипция под японским текстом: слова и примеры урока, цитата дня,

  (японские помечены флагом), скорость 0.5–1.5× и тон. Есть кнопка «Проверить голос».
  Если японского голоса нет, сайт честно скажет об этом.

## 🏆 Геймификация

Опыт (XP), уровни, задания, достижения, магазин и рейтинг работают поверх localStorage.

### Опыт и уровни

- XP начисляется за уроки (80), новые слова (5 за слово), верные ответы викторины (10),
  верные ответы на скорость (4), ежедневный вход (5), достижения (+25 за каждое),
  задания дня и челлендж недели.
- Порог уровня: `100·(n−1) + 50·(n−1)(n−2)/2`. Уровень 1 — 0 XP, 2 — 100, 3 — 250,
  4 — 450, 5 — 700… максимум 100 уровень.
- Каждый уровень даёт награду: титул, рамку, значок или акцентную тему.
  Награды за уже пройденные уровни выдаются автоматически при загрузке.

### Достижения — ровно 100

Список и условия — в `js/achievements.js` (`ACHIEVEMENTS`), иконки — там же
(`ACH_ICONS`, 47 SVG). Сетка в профиле: открытые оранжевые, закрытые серые,
есть фильтры «Все / Открытые / Закрытые». При открытии — всплывающее уведомление и +25 XP.

### Ежедневные задания, стрик и челлендж

- **Задания на сегодня** — 3 случайных квеста из 12, выбор стабилен в течение дня
  (сид от номера дня). Ключ `nihongo_daily`, сброс после полуночи.
- **Серия дней** — растёт ежедневно, при пропуске дня начинается заново,
  лучшая серия сохраняется. Блок на главной и в профиле.
- **Челлендж недели** — одно особое задание недели из 8, даёт XP и эксклюзивный значок
  (ключ `nihongo_weekly`).

### Викторина дня

5 вопросов из банка 36, выбор по дате. За верный ответ +10 XP, за прохождение +25 XP,
за 5 из 5 — бонус +30 XP. Одна попытка в день, ключ `nihongo_quiz`.

### Магазин — `shop.html`

27 предметов в четырёх категориях: 8 премиальных аватаров (avatar9–16), 4 акцентные темы,
5 рамок профиля и 10 значков. Покупка списывает XP, надетые предметы применяются
на всех страницах (рамка аватара, значок у ника, акцентный цвет). Ключ `nihongo_shop`.
Часть предметов нельзя купить — только получить за уровень или челлендж.

**Значки рисуются в SVG** (`js/badges.js`): щит с кандзи, 4 редкости — обычный, редкий,
эпический и легендарный. Галерея всех восьми значков с условиями открыта внизу магазина,
надетый значок заменяет эмодзи у ника в профиле и рейтинге.

### Рейтинг — `rating.html`

ТОП-100 по опыту: место, аватар, ник, уровень, XP и прогресс до следующего уровня.
Основа — аккаунты из `nihongo_users`; чтобы таблица не пустовала, рядом идут
24 демо-соперника: общая таблица на сервере пока не ведётся. Своя строка подсвечена, есть поиск по нику.

### Слабые места — `weakspots.html`

Каждый неверный ответ (тесты, викторина, экзамен, аудирование, карточки) пишется
в `nihongo_weak` с темой и верным вариантом. Блок в профиле и отдельная страница
показывают темы с наибольшим числом ошибок, долю от всех провалов и кнопку
«куда идти»: грамматика, карточки, аудирование или тесты. Разбор хранится и
чистится одной кнопкой.

### Цели на день и неделю — `goals.js`

Три пресета: спокойный (40 XP), обычный (100 XP) и серьёзный (200 XP), плюс цель
по урокам за неделю. Виджет стоит на главной и в профиле, прогресс считается по
`nihongo_xp_days` и журналу активности. Закрыл дневную норму — +25 XP бонусом,
один раз в день. Ключ `nihongo_goals`.

### Избранное — `favorites.html`

Звёздочка есть у тайтлов каталога, правил грамматики и слов словаря. Список живёт
в `nihongo_favorites`, показывается в профиле и на отдельной странице, сгруппирован
по разделам. Поиск и переходы сохраняют адрес: `anime.html?title=id`,
`grammar.html?rule=id`, `dictionary.html?q=слово`.

### Кандзи-пары — `match.html`

Мини-игра на память: 16 карточек, 8 пар «слово + перевод». Верная пара даёт +4 XP,
чистая партия — бонус. Время и ходы считаются, рекорд хранится в `nihongo_match`.
Уровень берётся из переключателя JLPT.

### Поиск по сайту — `search.html`

Одна строка ищет по урокам, словарю, грамматике, аниме, тестам и видео. Понимает
русский, ромадзи и кандзи: одиночный кандзи — уже полноценный запрос. Есть фильтры
по разделам, подсказки в результате и переход сразу в нужное место.

### Тема по времени суток

Опция в настройках, вкладка «Интерфейс»: с 7 до 18 — светлая, вечером обычная,
ночью сакура. По умолчанию выключена, ручной выбор темы всегда важнее.
Ключ `nihongo_autotheme`.

### Флешкарты — `flashcards.html`

Слова из словаря с интервальными повторениями: коробки 10 минут → 1 день → 3 → 7 → 16 → 35.
Верный ответ поднимает карточку выше, «Не помню» возвращает в первую. Два режима
(японский → русский и наоборот), сводка «к повторению / выучено / точность»,
клавиши `Space`, `1`, `2`, `3`. Ключ `nihongo_srs`.

### Аудирование — `listening.html`

Слово произносится голосом `ja-JP` через Web Speech API, нужно выбрать перевод
или вписать ромадзи. Серия верных ответов, точность и лучшая серия — в `nihongo_listening`.
Скорость и голос берутся из настроек, вкладка «Звук».

### Пробный экзамен JLPT — `exam.html`

20 вопросов из трёх секций (語彙, 文法, 読解), 10 минут, таймер в шапке, ответы
клавишами 1–4. После финиша — разбивка по секциям, история попыток и бонус:
80% и выше даёт +30 XP. Уровень берётся из переключателя JLPT.

### Друзья и рейтинг друзей

Заявка отправляется по нику: это либо аккаунт из этого браузера, либо один из
24 демо-игроков рейтинга. Общего сервера нет, поэтому демо-соперник «принимает»
заявку через пару секунд, а реального игрока можно принять вручную.
Список — в `nihongo_friends`, счётчик и кнопки удаления — в профиле.
На `rating.html` две вкладки: ТОП-100 и таблица только среди друзей;
`rating.html#friends` сразу открывает вторую.

### Уровень JLPT — N5 / N4 / N3

Переключатель живёт в шапке каталогов (`lessons.html`, `anime.html`, `dictionary.html`,
`grammar.html`, `tests.html`), в профиле и отдельной вкладкой в настройках.
Выбор сохраняется в `nihongo_jlpt` и в аккаунте, после чего уроки, тесты, слова,
правила и тайтлы фильтруются по уровню. Если на уровне пока нет материалов,
показывается подсказка с кнопкой «Показать все». В профиле и настройках —
прогресс по каждому уровню (сколько уроков пройдено из скольких).

### Публичный профиль

`profile.html?user=ник` открывает профиль без входа: шапка с аватаром, уровнем,
опытом, стриком и достижениями, ссылка копируется кнопкой «Ссылка» в своём профиле.
Личные блоки (настройки, друзья, выход) в этом режиме скрыты, страница помечена классом
`public-profile`, а `document.title` меняется на «ник — профиль AniLingo».
Работает и для демо-игроков рейтинга — они помечены как демо.

### Оформление профиля

Шесть градиентов шапки, пять акцентов, четыре эффекта ника (свечение, градиент, зеркало),
а также свечение интерфейса, «стекло» и компактный режим. Всё хранится в `nihongo_custom`.
Акцент из оформления не перебивает купленную тему магазина: тема важнее.

### История активности и графики

Каждое действие (урок, слово, тест, достижение, друг, уровень) пишется в `nihongo_activity`
и показывается в профиле лентой по дням с фильтрами: всё, учёба, награды, общение.
Графики рисуются без библиотек, на чистом SVG: столбики опыта за 14 дней, кольца
прогресса по словам / урокам / достижениям и мини-график в шапке профиля.

### Загрузка при переходе между страницами

`js/loader.js` подключён в `<head>` на всех страницах. Перед переходом он показывает
оверлей с логотипом-тории, спиннером, полосой прогресса и подписью «Загружаем…»,
а на новой странице проявляет его ещё до отрисовки контента — поэтому нет ни мигания,
ни «прыжка» страницы. Минимальный показ 420 мс, чтобы оверлей не мелькал на быстрых
страницах, дальше он плавно уходит сам. Не перехватываются: внешние ссылки, `target="_blank"`,
`download`, якоря на этой же странице, Ctrl/⌘/Shift-клики и ссылки с `data-no-loader`.
Возврат из кеша браузера (`pageshow`) оверлей снимает.

### Меню «Ещё» по категориям

Вместо длинной простыни из 16 пунктов — четыре группы: Учёба, Практика, Прогресс и Разное.
Открыта всегда одна группа (аккордеон), панель ограничена по высоте (`min(74vh, 470px)`)
и прокручивается, а группа с текущей страницей раскрывается сама. На телефоне те же
группы попадают в бургер-меню плоским списком.

### Уведомления, палитра команд и горячие клавиши

Колокольчик в шапке (`notify.js`) собирает события: новые уровни, карточки к повторению,
результаты экзамена. Одинаковые события за день схлопываются, счётчик показывает
непрочитанные, всё хранится в `nihongo_notifications`.

`Ctrl/⌘ + K` открывает палитру команд (`hotkeys.js`): поиск по 16 страницам и действия
вроде смены темы. `?` — шпаргалка по клавишам, `T` — следующая тема, `P` — профиль.

### Перенос прогресса — `backup.js`

В настройках, вкладка «Аккаунт»: «Скачать прогресс» отдаёт один JSON со всеми ключами
`nihongo_*`, «Загрузить прогресс» восстанавливает их из файла. Импорт проверяет формат
и не трогает чужие ключи localStorage. Рядом — «Сбросить всё» с подтверждением.

### Недельный отчёт и сертификат

В профиле появился отчёт за 7 дней: сумма XP, сравнение с прошлой неделей, лучший день,
активные дни и столбики по дням (`report.js`). Там же кнопка «Сертификат» — картинка
PNG 1200×850 с ником, уровнем, опытом и достижениями, рисуется на canvas без библиотек
(`certificate.js`).

### Конспект урока

Кнопка «Конспект» на странице урока собирает слова, теорию и примеры в аккуратный
лист и открывает печать — оттуда можно сохранить PDF. Печатные стили лежат
в `css/print.css`, поэтому в файл не попадают меню, сакура и фон.

### Мобильная версия

До 900 px в шапке появляется бургер, ссылки из панели «Ещё» дублируются в меню,
все сетки становятся одноколоночными, поле «Кандзи-пар» — 2×2, кнопки и звёздочки
получают размер под палец. Модалки не выше 88% экрана, таблицы прокручиваются
по горизонтали.

### Меню на телефоне — выезжающая панель

До 900 px бургер открывает панель справа: `.nav` становится `position: fixed`
на всю высоту, под ней затемнение `.nav-backdrop`, клик по фону и крестик
в шапке панели закрывают её, страница в это время не скроллится (`body.nav-open`).
У шапки на телефоне отключён `backdrop-filter` — он создавал новый containing block
и «приклеивал» панель к тексту вместо того, чтобы выводить её поверх страницы.

### Плавный скролл — `smoothscroll.js`

Колесо мыши и тач-жесты прокручивают страницу с инерцией (`ease: 0.14`),
переходы по якорям учитывают высоту шапки. Вложенные прокрутки (модальное тело,
палитра команд, панель уведомлений, `.cs-menu`) не перехватываются.
Плавность отключается, если в системе включено «уменьшить движение»,
если в настройках выключены анимации интерфейса или если устройство только
с тач-вводом. `window.smoothScrollTo(top)` — прокрутка из кода.

### Аниме-оформление — `anime-style.js`

К каждому разделу добавляются детали постера: точечная сетка-полутон,
крупная вертикальная надпись на полях (для каждой страницы своя —
`地図`, `言葉`, `試験`…), мерцающие звёзды у заголовков и мягкий 3D-наклон карточек
под курсором. Наклон пересобирается по событию `anime-grid-rendered`, которое
каталог аниме отправляет после каждой перерисовки сетки.

Волна 12 добавила «кадр»: четыре уголка по краям экрана, метку эпизода
(`第壱話` … `第二十六話` — своя у каждой из 26 страниц) и вертикальный
штрих-код. Под шапкой один раз пробегает катакана-строка, потом сама
удаляется из DOM. При нажатии на главные кнопки разлетаются искры,
у разделов стоят крупные номера, у карточек аниме — подсказка `開く`.
Всё это только `transform` и `opacity`, поэтому телефону не мешает.

Надпись на полях ставится через класс `.has-side-mark`: без своего
контекста позиционирования абсолютный элемент уезжал бы в начало документа.

### Плавность — `perf.js` и `perf.css`

`perf.js` сразу при загрузке решает, сильное ли устройство:
`prefers-reduced-motion`, окно ≤ 900 px, ≤ 4 ядер или ≤ 4 ГБ памяти —
значит телефон. Тогда на `<html>` появляется класс `.perf-lite`, и
`perf.css` меняет дорогое на дешёвое, не тронув вид:

- гасит бесконечные анимации (блики по кнопкам, пульсации, мерцание);
- `backdrop-filter` шапки и панелей заменяет плотной подложкой того же цвета;
- упрощает тени, убирает полноэкранные слои (полутон, манга-края, скорость);
- уменьшает количество лепестков сакуры.

Скрытая вкладка получает `.perf-hidden` — анимации встают на паузу.
Ручной переключатель «Лёгкая графика» (Настройки → Интерфейс) пишет
`nihongo_light_graphics = 'off'` и включает тот же режим на компьютере.

### Обучение — `onboarding.js`

Тур из пяти шагов: меню, дизайн, каталог, прогресс и подвал. Карточка шире
(470 px, на телефоне — во всю ширину), заголовок 21 px, текст 15 px,
под каждой подсветкой — пульсирующая подсказка «куда нажать» и стрелка,
сверху — полоса прогресса и точки шагов. Для телефона у шагов свои
`mobileSelector`, элемент ищется заново на каждом шаге (меню может быть
скрыто), ищется и `fallbackSelector`. Тур запускается один раз (флаг
`nihongo_tour_done`), повторно — кнопкой в настройках или `restartTour()`.
Интерфейс тура на русском, поэтому при другом языке интерфейса он не показывается.

### Своя музыка и плеер — `player.js`

Плейлист живёт в `nihongo_playlist` (до 12 треков по 1,8 МБ), состояние —
в `nihongo_player`. Плеер в правом нижнем углу умеет:

- паузу, перемотку по полосе и кнопки ±10 секунд;
- переключение треков вперёд и назад, удаление и добавление файлов;
- отдельную громкость (синхронна с ползунком в настройках);
- сворачивание в виниловый диск — открывается одним кликом;
- **Spotify по ссылке**: `open.spotify.com/...` или `spotify:track:...`
  превращается во встроенный плеер (трек, альбом, плейлист, подкаст, эпизод).
  Ничего не скачивается — в `nihongo_playlist` лежат только тип и id,
  а звук идёт с серверов Spotify;
- перемешивание и повтор одного трека или всего плейлиста;
- продолжение трека при переходе между страницами: позиция и состояние
  сохраняются перед уходом и восстанавливаются на новой странице
  (браузер может попросить клик — тогда плеер так и напишет).

### Свой фон, цвет и курсоры — `customize.js`

Всё хранится в localStorage, ничего не уходит на сервер.

| Что | Ключ | Детали |
| --- | --- | --- |
| Свой фон | `nihongo_custom_bg` | файл ужимается в canvas до 1920 px, JPEG q0.82 |
| Затемнение / размытие | `nihongo_bg_dim`, `nihongo_bg_blur` | 0–90% и 0–20 px |
| Свой цвет акцента | `nihongo_accent` | HEX → HSL, весь сайт перекрашивается через `--accent` |
| Радужный режим | `nihongo_accent_rainbow` | `@property --accent-hue` + 16-секундный цикл |
| Плейлист | `nihongo_playlist` | до 8 треков по 1,8 МБ, см. `player.js` |
| Курсор | `nihongo_cursor` | обычный, акцентный и 7 аниме-курсоров (SVG в data URL) |

Палитра — 8 готовых оттенков плюс любой свой цвет. Курсоры: катана, сакура,
звезда, сюрикэн, онигири, кицунэ, сердце. Кнопка «Загрузить свой курсор»
пока показывает пояснение — загрузка появится позже.

Переменная `--cursor-image` хранит только `url(...)` и координаты: запасной
`auto` дописывает CSS. Если добавить его в переменную, значение `cursor`
становится невалидным и курсор не меняется — на это легко наступить.

### Тема: выбор человека всегда главный

Тема хранится в двух местах — `theme` и `settings['interface.theme']` — и
применяется классом к `<body>` (`theme-sakura`, `theme-light`). Если включён
авто-режим «тема по времени суток», ручной выбор его отключает: иначе
`applyAutoTheme()` перебивала сакуру светлой темой при каждом переходе.
Дополнительно тема переприменяется на `load` и `pageshow` — после возврата
из кеша браузера она тоже остаётся прежней.

### Размер текста — на весь сайт

Все размеры шрифтов в `css/style.css` переведены в `rem` (база — `html`,
15 px). Настройка «Размер шрифта» ставит `font-size` на `<html>`, поэтому
масштабируется весь интерфейс: меню, карточки, таблицы, подвал, окна,
а не только основной текст. Слайдер — 13…19 px.

### Поля ввода: вставка и автозаполнение

Раньше автозаполнение красило поле жёстким тёмным `#14141d` через
`box-shadow`, и в светлой теме вставленный текст оказывался под тёмным
прямоугольником. Теперь цвет берётся из темы (`var(--bg-elev)`), текст
всегда `var(--text-main)`, у полей явные `-webkit-text-fill-color` и
`caret-color`. У `.auth-card` и `.settings-content` убран
`backdrop-filter` — Chrome иногда рисовал на нём серый слой поверх текста.
Плюс `bindPasteFix()` в `prefs.js`: после вставки поле получает класс
`just-pasted` и перерисовывается.

### Производительность

- `smoothscroll.js` — один rAF-цикл с предохранителями: не больше 240 кадров,
  остановка, если страница не двигается, стоп в фоновой вкладке. Раньше цикл
  мог крутиться бесконечно, если прокручивать было уже некуда.
- `loader.js` — оверлей перехода больше не может «застрять»: сторожевой
  таймер (`forceUnlockPage`) снимает блокировку прокрутки через 7 секунд,
  на `pageshow` и при возврате во вкладку.
- `design.js` — лепестки не пересобираются, если их уже столько же;
  на телефонах и слабых устройствах их вдвое меньше; таймер релиза тикает
  раз в секунду только пока виден.
- `anime-style.js` — наклон карточек считается через `requestAnimationFrame`,
  а не на каждое движение мыши.
- `icons.js` и `i18n.js` не тратят кадры в фоновой вкладке.
- В фоновой вкладке CSS-анимации ставятся на паузу (`body.is-hidden`).

### Удаление аккаунта — с кодом на почту

«Настройки → Аккаунт → Удалить аккаунт» открывает окно с полем для кода.
Код отправляется на почту аккаунта (`apiSendCode`), проверяется
`apiVerifyCode`, и только после этого `apiDeleteAccount` удаляет запись.
Пока код не отправлен, кнопка «Удалить навсегда» заблокирована. Так как
сервера нет, письмо не уходит: код показывается на экране и подставляется
в поле — как и при регистрации.

### Настройки без заглушек

Каждый переключатель из `settings.js` сразу пишется в `localStorage` (`settings`)
и применяется на месте: звук, музыка, уведомления, язык интерфейса, тема, фон,
курсор, компактный режим, размер шрифта, ромадзи, транскрипция, перевод,
пасхалки, сакура, аватар. Живое применение — в `bindLiveSettings()`,
повторное применение при загрузке — `applyAllPreferences()` из `prefs.js`.
Без изменений остаются только функции, которым нужен сервер: двухфакторная
защита, DNS и прокси лаунчера, письма на почту — рядом с ними так и написано.

### Аккордеоны профиля — `collapse.js`

Четырнадцать блоков профиля сворачиваются кликом по заголовку, состояние
хранится в `nihongo_blocks`. Рядом — «Свернуть все» / «Раскрыть все»
(`toggleAllBlocks()`). Карточка с аватаром липкая (`position: sticky`), поэтому
кнопка «Изменить аватар» остаётся на виду при прокрутке блоков.

### Обновления — `updates.html`

История проекта по волнам: от фундамента до аналитики ошибок и мобильной версии.

### Офлайн-режим

`manifest.json` + `sw.js`: сайт устанавливается как приложение и открывается без сети.
Стратегии аккуратные — HTML и JS всегда сначала из сети (чтобы правки прилетали сразу),
картинки из кеша. Если сеть пропала, навигация уходит на `offline.html`, а в шапке
появляется плашка «офлайн». Регистрация — в `pwa.js`, только по https и localhost.

### Тест на скорость — `speed.html`

60 секунд, хирагана, катакана, слова и фразы. Верный ответ +4 XP, каждые 5 подряд —
бонус +10 XP, в конце бонус за результат. Клавиши 1–4. Рекорд и число попыток
хранятся в `nihongo_speed`.

### Отсчёт до открытия — 250 дней

Дата старта хранится в `nihongo_release_start_v2`. Полоса готовности и
процент считаются от прошедшего времени (`getReleaseProgress()`): каждый
день она прибавляет ~0,4%, а часы, минуты и секунды тикают в реальном
времени. Когда 250 дней истекут, таймер покажет нули и «платформа открыта».
Старт можно перезапустить, удалив ключ в DevTools.

Аниме-стиль усиливают точечный полутон, вертикальные надписи на полях,

Часть 17 добавляет манга-детали: пунктирная рамка внутри карточек при

`overflow-x: clip` (с запасным `hidden` для старых браузеров) не мешает
липким блокам, в отличие от `hidden`.

- **Три темы:** Стандарт (тёмная), Сакура (розовая), Светлая. Переключаются в панели

- **Переходы:** `0.25s cubic-bezier(0.4, 0, 0.2, 1)`.
- **Адаптивность:** базовые точки 980 и 720 px для новых блоков; полноценная

| **Звук** | Громкость, музыка, звуки кнопок, уведомлений, перевода |

Все значения реально пишутся в localStorage (`settings`) и восстанавливаются при
следующем заходе: тема, фон, курсор, шрифт, анимации, компактный режим, форма
аватара, сакура, язык, громкость, уведомления, прокси и DNS.

соединения реально запрашивает файл сайта, удаление аккаунта стирает запись
из `nihongo_users` и закрывает сессию.

Выпадающие списки — не системные `<select>`, а свои окна (`js/select.js`):
клавиатура, поиск значения по стрелкам, закрытие по Esc и клику мимо.

На компьютере разделы стоят меню слева. На телефоне это компактная кнопка
«Раздел настроек»: она поднимает снизу окошко со списком — с полоской-ручкой,
за которую панель тянут вниз, чтобы закрыть (порог 80 px, короткий свайп
возвращает её на место). Закрывается ещё кликом по затемнению, кнопкой
«Закрыть», Esc и поворотом экрана в альбомную ширину. Пока окошко открыто,
страница не прокручивается (`html.settings-sheet-open`).

## 🪟 Окна и вкладки

Все модальные окна собираются по одному принципу — как карточка аниме:

- **Шапка** не скроллится, **тело** прокручивается, **кнопки** всегда внизу.
- `js/modals.js` сам разбирает окно на три части: переносит содержимое в
  `.modal-body`, а последний ряд кнопок — в `.modal-foot`. Работает и для окон
  из HTML, и для тех, что рисуют скрипты (донат, cookies, привязка соцсетей).
- Высота окна — не больше `86vh` (`92vh` на телефоне), поэтому кнопки не
  уезжают за экран даже на маленьком ноутбуке.
- Окна, которые перерисовывают тело целиком (карточка аниме), помечаются
  `data-modal-nofoot` — у них кнопки остаются внутри прокрутки.
- Кнопки в окнах компактнее страничных и одинаковой ширины; длинные подписи
  переносятся, а не вылезают за край.
- Боковые панели (дизайн, палитра команд, уведомления, шпаргалка) получили
  свою прокрутку вместо обрезки.

На телефоне «вкладки» тоже приведены в порядок: меню настроек стало
горизонтальной полосой сверху, сохранение — на всю ширину, а форма входа
в `register.html` идёт раньше рассказа о платформе.

## 🎨 Цвет сайта: три числа на всё

Сайт больше не оранжевый. Базовая тема — чёрный и графит: серые кнопки,
серые свечения, обесцвеченная фотография фона. Жёлтого оттенка нет нигде,
включая печатные стили и служебные страницы.

### Как устроено

Весь цвет считается из трёх чисел в `:root` файла `css/style.css`:

```css
--accent-hue: 220;   /* оттенок 0–360 */
--accent-sat: 6%;    /* насыщенность */
--accent-l: 64%;     /* светлота */
```

Из них собираются `--accent`, `--accent-2`, `--accent-3`, `--accent-dark`,
`--accent-soft`, `--accent-text` и `--accent-ink`. Каждый акцентный элемент
в стилях написан как `hsl(var(--accent-hue) var(--accent-sat) …)`, поэтому
смена трёх чисел перекрашивает **весь** сайт: кнопки, рамки, бейджи, тени,
свечения, скроллбар, выделение текста.

Производные переменные объявлены селектором `:root, body` — так тема может
задать свои три числа прямо на `body` и перекрасить всё внутри страницы.

### Где менять

| Место | Что даёт |
|---|---|
| Панель дизайна (кнопка «Дизайн» в шапке, есть на всех страницах) | 8 кружков палитры + свой цвет |
| Настройки → Интерфейс → «Цвет сайта» | та же палитра, свой цвет и радужный режим |

Выбор хранится в `nihongo_accent_preset` (id палитры) и `nihongo_accent`
(свой цвет, `#rrggbb`), применяется на каждой странице через
`js/customize.js` → `applyAccentSettings()`.

### Что следует за цветом

- `js/charts.js` — графики и кольца прогресса (`chartAccent()`);
- `js/badges.js` — легендарные значки (`badgeAccent()`);
- `js/certificate.js` — рамка и заголовок сертификата (`certificateAccent()`);
- `js/shop.js` — темы магазина задают те же три числа из своего цвета;
- `js/profile-custom.js` — акцент в оформлении профиля.

Для canvas и SVG, где CSS-переменные не работают, есть
`getAccentColor(shift, alpha)` — возвращает готовую строку `hsl(...)`.

### Темы

| Тема | Что делает |
|---|---|
| Стандарт | графит на чёрном |
| Сакура | меняет три числа на розовые (оттенок 340) |
| Светлая | белый фон, тёмный акцентный текст, светлые плашки |

## 🧠 Волна 10: учёба, поиск и фокус

### Подсказки в поиске — `js/search-data.js` + `js/suggest.js`

`SEARCH_SUGGESTIONS` — один массив на весь сайт (уроки, ряды каны, слова, аниме,
грамматика, страницы). `searchSuggestions(query)` возвращает первые **5** совпадений:
сначала точное начало названия, потом вхождение, потом ключевые слова.

Подсказки подключаются к полям `#searchInput`, `#lessonSearch`, `#animeSearch`,
`#grammarSearch` и к любому полю с атрибутом `data-suggest`. На главной у поля есть
`data-suggest-go="search"` — Enter уводит на `search.html?q=…`. Стрелки ↑/↓ выбирают
строку, Enter открывает, Esc закрывает.

### Продолжить урок — `js/study.js`

Ключ `nihongo_active_lesson`: `{ lessonId, currentStep, totalSteps }`, его пишет
`js/lesson-tools.js` при заходе в урок и после каждого шага. На главной
`getActiveLesson()` отдаёт запись, только если урок ещё не пройден, — из неё
строится кнопка «Продолжить: …» со ссылкой `lesson.html?id=N&resume=true`.
Страница урока по этому параметру прокручивает к первому незакрытому шагу.

### Случайный урок

`pickRandomLesson()` берёт случайный урок из непройденных, а если пройдено всё —
из всех. Кнопка стоит рядом с «Продолжить».

### Режим фокуса — `js/lesson-tools.js`

Кнопка с глазом в шапке урока. Включает `body.focus-mode`: прячутся `.header`,
`.footer`, `.design-panel`, `.lesson-nav`, урок остаётся одним столбцом.
Состояние — `nihongo_focus_mode` (`'1'` / `'0'`). Выход — кнопка слева внизу или Esc.

### Помодоро

Панель в правом верхнем углу урока: 25 минут, «Старт / Пауза / Сброс», полоса прогресса.
Состояние — `nihongo_pomodoro`: `{ running, endsAt, left }`, поэтому таймер переживает
перезагрузку. Когда время вышло — тост «Пора отдохнуть 5 минут».

### Дневник ошибок — `js/mistakes.js`

Ошибки пишут тесты, викторина, экзамен, аудирование, карточки и тест урока через
`recordMistake()` из `js/weakspots.js`. Массив лежит в `nihongo_weak` — это и есть
«массив mistakes». Блок «Слабые места» в профиле переделан в «Дневник ошибок»:
таблица «слово / правильный ответ / твой ответ / Повторить», сводка слабых тем
осталась под ней. Кнопка «Повторить» открывает мини-тест; верный ответ удаляет
запись из дневника, неверный — оставляет.

### Карта прогресса — `js/progress-map.js`

Сетка карточек на `lessons.html`: `.lesson-card.completed` (оранжевые),
`.lesson-card.current` (пульсирует), `.lesson-card.locked` (серые). Статус считается
из `nihongo_progress` и `nihongo_completed_lessons`.

### Быстрый повтор — `js/quick-review.js`

Пять карточек из слов, которые учили вчера: `nihongo_words_log` хранит
`{ ru, romaji, date }` по каждому слову. Если вчера занятий не было — берутся
слова из журнала, потом из копилки. Клик переворачивает карточку (`rotateY`).

### Озвучка выделенного — `js/tts-select.js`

Выделили японский текст → рядом появилась кнопка «Озвучить». Работает через
`speakJapanese()` (голос, скорость и тон из настроек), а если её нет на странице —
через `SpeechSynthesisUtterance` с `lang = 'ja-JP'`.

### Темп учёбы

Ползунок 5–30 минут на вкладке «Интерфейс» в настройках. Значение — `nihongo_study_pace`
и `study.pace` в общих настройках. Карточек на урок = темп / 5: `#paceCards` на
странице урока показывает ровно столько карточек, сколько положено по темпу.
На главной блок «Продолжим?» пишет рекомендованное время на день.

### Точка «сегодня занимался»

`markStudyDone()` пишет `nihongo_last_study` (YYYY-MM-DD) и зажигает зелёную точку
`.study-dot.is-today` рядом с логотипом. Вызывается после урока, викторины,
флешкарт, повтора ошибок и мини-игры.

### Напоминание о перерыве

`js/study.js` проверяет время каждые 10 минут. Если страница открыта больше часа
и игрок не простаивал дольше 5 минут — тост «Ты учишься час. Отдохни 5 минут».

### Мини-игра «Собери слово» — `game.html` + `js/game.js`

Слоги перемешаны, нужно собрать слово с подсказкой-переводом. 30 секунд: верное
слово +10, неверный слог −5 и слово начинается заново. Рекорд — `nihongo_game_best`.
Страница собрана на тех же классах, что и «Скорость», поэтому выглядит родной.

### Переворот аватара

`animateAvatarChange()` в `js/avatar.js` вешает `.avatar-changing` на карточку и на
все `[data-avatar-img]`; CSS крутит `@keyframes flip` 0.5 с и снимает класс.

### Офлайн

`manifest.json`, `sw.js` и `js/pwa.js` уже были — волна 10 добавила в `CORE` новые
страницы и скрипты и подняла `VERSION` до `nihongo-v8`, чтобы старый кеш не мешал.

## ⚡ Скорость каталога аниме

- Постеры для сетки — облегчённые копии в `assets/images/posters/web/`
  (440 px, JPEG q72): было ~2.9 МБ, стало ~1.2 МБ.
