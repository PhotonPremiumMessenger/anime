# ⛩ Nihongo — учи японский через аниме

**Сайт работает на GitHub Pages. Данные хранятся в localStorage браузера.**

Фронтенд платформы Nihongo: разборы фраз, пасхалок и культурных отсылок из аниме
для русскоязычных анимешников. Чистый HTML, CSS и JavaScript — без React, Vue,
сборщиков и серверного кода.

---

## 🚀 Как открыть

### Локально

Скачай папку проекта и открой **`index.html`** в браузере (двойной клик). Всё.

Если браузер ограничивает `file://` — запусти локальный сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000
```

### На GitHub Pages

1. Залей ветку в репозиторий (или влей PR).
2. Открой **Settings → Pages**.
3. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**.
4. Сохрани — через минуту сайт будет на `https://<username>.github.io/<repo>/`.

Ссылки в проекте относительные, поэтому сайт работает и в подпапке, и локально.

**Никакого бэкенда не нужно.** Регистрация, вход, прогресс и достижения живут
в браузере пользователя. Сторонние сервисы: только Google Fonts и Google Translate
(перевод выделенного текста).

## 👤 Аккаунты и сессия

| Ключ localStorage | Что хранит |
| --- | --- |
| `nihongo_users` | Массив аккаунтов `{ username, email, password, avatar, createdAt }` |
| `nihongo_current_user` | Ник текущего пользователя (сессия) |
| `nihongo_token` | Псевдо-токен сессии (32 случайных символа) |
| `nihongo_progress` | Прогресс: уроки, слова, серия дней |
| `nihongo_achievements` | Открытые достижения |

**Регистрация:** ник (3–20 символов), почта, пароль (8+). Проверяется, что ник и
почта не заняты. После создания аккаунта вход выполняется автоматически.

**Вход:** ник (или почта) и пароль. При успехе сохраняются токен и ник, дальше — редирект на `profile.html`.

**Выход:** очищаются `nihongo_current_user` и `nihongo_token`, редирект на `index.html`.

**Защищённые страницы:** `profile.html`, `settings.html`, `lesson.html`.
Без токена — редирект на `register.html`; после входа пользователь возвращается
на ту страницу, с которой его выкинуло.

### Про код подтверждения

Почты нет, письмо не отправляется. Код из 10 символов генерируется в браузере,
показывается в уведомлении и автоматически подставляется в поле. Он действует
10 минут и привязан к введённой почте — логика подтверждения осталась, просто
целиком на клиенте.

> Пароли хранятся в localStorage в открытом виде — это демо-проект без сервера.
> Никогда не используйте здесь настоящие пароли.

## 📚 Уроки

Пять уроков в `js/lessons-data.js` (массив `nihongo_lessons`):

| № | Урок | Уровень | Время |
| --- | --- | --- | --- |
| 1 | Хирагана | N5 | 15 мин |
| 2 | Катакана | N5 | 15 мин |
| 3 | Приветствия | N5 | 12 мин |
| 4 | Фразы из аниме | N4 | 20 мин |
| 5 | Частицы は, が, を | N5 | 18 мин |

В каждом уроке: 10 слов с романдзи и переводом, блок грамматики, 4 примера
и тест из 5 вопросов.

- `lessons.html` — каталог: поиск, фильтр по уровню, прогресс-бар на каждой карточке.
- `lesson.html?id=N` — сам урок: озвучка слов, примеры, тест с проверкой.

**Озвучка** — Web Speech API (`speakJapanese`), голос `ja-JP`. Кнопка 🔊 стоит
рядом с каждым словом и примером. Если японского голоса в системе нет, браузер
прочитает текст своим — сайт подскажет об этом.

**Проверка теста:** верные ответы подсвечиваются зелёным, ошибочные — красным.
Кнопка «Завершить урок» сохраняет результат в `nihongo_progress`.

## 🏆 Достижения

Шесть штук, открываются автоматически после действий:

| Достижение | Условие |
| --- | --- |
| 👣 Первый шаг | выучено первое слово |
| 🌸 Первый урок | пройден первый урок |
| 📚 10 слов | 10 слов в копилке |
| 🗣 100 слов | 100 слов в копилке |
| 🔥 Неделя подряд | 7 дней занятий подряд |
| 🎌 Мастер аниме | пройдены все уроки |

Прогресс и достижения видны в профиле. Серия дней обновляется при завершении урока:
занятие сегодня, вчера — продолжаем счёт, пропуск — начинаем заново.

## 🎨 Дизайн

Тёмное «стекло» с оранжевым акцентом, объёмные карточки, свечение и 3D-эффекты.

- **Логотип:** SVG-тории + «日本語 NIHONGO» с оранжевым свечением, ведёт на главную.
- **Три темы:** Стандарт (тёмная), Сакура (розовая), Светлая. Переключаются в панели
  «Дизайн» и в настройках, сохраняются в localStorage.
- **Кнопки:** подъём + масштаб + оранжевое свечение при наведении, `scale(0.98)` при нажатии,
  внутренняя и внешняя тень для объёма.
- **Карточки:** подъём с наклоном `perspective + rotateX`, свечение по рамке.
- **Сакура:** объёмные лепестки с 3D-вращением по трём осям и тенями. Включается
  в панели дизайна, количество задаётся «уровнем сакуры» в настройках.
- **Переходы:** `0.25s cubic-bezier(0.4, 0, 0.2, 1)`.
- **Адаптивность:** не делалась — по заданию только ПК-версия.

Все переменные темы лежат в начале `css/style.css`.

### Изображения

- `background.jpg` — атмосферный ночной пейзаж с тории и сакурой;

Изображения сгенерированы специально для проекта и лежат локально — внешние
CDN не используются, лицензионных ограничений нет.

## 🌐 Перевод при выделении

Выдели текст на любой странице — над выделением появится попап.

- Русский → японский, японский → русский (определяется автоматически).
- Основной источник — Google Translate, резервный — MyMemory.
- Позиция над выделением; у края экрана попап не выходит за границы.

## ⚙️ Настройки

Шесть разделов, все сохраняются в localStorage:

| Раздел | Что внутри |
| --- | --- |
| **Аккаунт** | Пароль, почта (с кодом), ник (раз в 30 дней), Discord, Telegram, 2FA, выгрузка данных |
| **Звук** | Громкость, музыка, звуки кнопок, уведомлений, перевода |
| **Интерфейс** | Язык, светлая тема, тема оформления, фон, курсор, шрифт, анимации, компактный режим |
| **Уведомления** | Уроки, аниме, друзья, достижения, дейли-напоминание, рассылка |
| **Лаунчер** | Публичный профиль, прокси, DNS |
| **Фишки** | Стиль перевода, транскрипция, пасхалки, уровень сакуры, стиль аватара |

Работают по-настоящему: смена пароля, ника и почты, темы, фон, шрифт, анимации,
компактный режим, форма аватара, сакура, выгрузка данных.
Остальные настройки сохраняются и показывают «Сохранено (заглушка)».
